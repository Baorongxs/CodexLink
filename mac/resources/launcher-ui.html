CodexLink 使用教程

CodexLink 是一款简易高效的 Codex 启动工具，可简化 Codex 安装、API 导入、程序启动等全套操作流程，同时内置多项功能优化，大幅降低使用门槛，提升用户使用体验。

详细使用步骤

1
账号登录

完成账号注册并登录 CodexLink 客户端。

2
安装 Codex 启动器

点击【安装Codex】，可二选一完成下载安装：

微软商店在线下载离线安装包下载

Mac 用户需根据自身电脑芯片型号，选择对应的适配版本下载安装。

3
自动导入 API

点击【导入API】，工具将自动生成、配置并保存 API 令牌，无需手动操作。

4
选择 API 分组

支持分组切换使用 API，其中 PLUS、PRO 两大分组各配备 4 条可用线路。若当前分组线路无法正常使用，直接切换其他分组即可恢复使用。如需切换为官方账号模式，勾选开启【官方开关】即可。

5
账户余额充值

点击【充值】，确保账号内有可用余额，即可直接使用 Codex。

功能补充说明

切换 API 分组后，工具会自动匹配对应分组的 API 令牌，并自动重启 Codex 程序，无需用户手动重启，全程自动化完成。
